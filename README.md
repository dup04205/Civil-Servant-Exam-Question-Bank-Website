# 공무원 기출문제 은행 (Civil Servant Exam Question Bank)

국가직·지방직 9급·7급 최근 5개년 공무원 기출문제 및 문제별 상세 해설 XML 아카이브와, 이를 SQLite 데이터베이스로 연동하여 풀이·오답노트·법령 검색·실전 모의고사를 지원하는 웹 애플리케이션입니다.

> **데이터 출처 및 라이선스**: 인사혁신처 사이버국가고시센터 기출문제 데이터셋 (**공공누리 제1유형** — 출처 표시 조건 하에 상업적·비상업적 이용 및 변경 가능) · 법령 조문 검증: 법제처 국가법령정보센터

---

## 1. 프로젝트 구조

```text
.
├── 공무원_기출문제/           # 국가직·지방직 9급·7급 5개년 직렬별 문제·해설 XML (총 4,689개 파일)
│   ├── index.xml              # 전체 직렬·연도·과목별 카탈로그 인덱스
│   ├── README.md              # XML 아카이브 및 법령 검증·오류 보정 상세 내역
│   ├── 국가직/ (9급, 7급)
│   └── 지방직/ (9급, 7급)
└── exam_bank/                 # HTML / CSS / JS 분리 웹 앱 + SQLite ETL & 서버
    ├── index.html             # 문제 은행 UI (시험지 풀기, OMR, 검색, 오답노트, 통계)
    ├── css/styles.css         # 통일된 문제 본문·지문·보기·도표 스타일시트
    ├── js/
    │   ├── api.js             # SQLite 백엔드 REST API 클라이언트
    │   ├── renderer.js        # XSS 안전 DOM 조립 및 본문 문단·표·보기 통일 렌더러
    │   └── app.js             # 상태 관리, 모의고사 타이머, 채점·오답노트·북마크 제어
    ├── build_db.py            # XML 아카이브 → SQLite DB(exam_bank.db) 생성 스크립트
    └── server.py              # Python 표준 라이브러리 기반 정적/API 웹 서버
```

## 2. 로컬 실행 방법

외부 Python 패키지 설치 없이 **Python 3.9+** 표준 라이브러리만으로 즉시 실행할 수 있습니다.

### ① SQLite 데이터베이스 생성 (`exam_bank.db`)
보안 및 용량 관리를 위해 바이너리 DB 파일(`exam_bank.db`)은 저장소에 포함하지 않았습니다. 클론 후 아래 명령어로 XML 데이터를 DB에 적재하세요.

```bash
python3 exam_bank/build_db.py
```
- 생성 결과: 고유 시험지 **830종**, 직렬 매핑 **2,344건**, 고유 문항 **16,760개**, 해설 **16,760개**

### ② 웹 서버 실행 및 접속

```bash
python3 exam_bank/server.py
```

## 3. 주요 기능

- **직렬·연도·과목별 시험지 풀기**: 국가직/지방직, 9급/7급, 직렬, 연도, 과목 계층 필터 지원
- **문제 본문 스타일 통일**: 과목별로 상이한 제시문 문단, `<보기>(ㄱ·ㄴ·ㄷ·ㄹ)`, 마크다운 도표, 밑줄·기울임·첨자·빈칸·수식 표기를 단일 디자인 시스템으로 정규화 렌더링
- **학습 모드 & 실전 모의고사 모드**: 즉시 정답/해설 확인 또는 OMR + 타이머 기반 일괄 채점 및 `exam_sessions` 성적 저장
- **법제처 조문 검증 수록**: 행정법·헌법·세법·관세법·형법·형사소송법·노동법·공직선거법 등 주요 법령 문항에 현행 법령ID·시행일·핵심 조문 근거 제공
- **SQLite DB 영구 연동**: 풀이 기록, 오답노트 자동 수집, 북마크, 개인 학습 메모, 키워드·법령 검색 지원
